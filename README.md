🎮 MORPH: Portal Shift — Game Plan 🎮

1. The Game Idea
Genre: 3D Puzzle Platformer
Theme: Sci-fi Test Chamber
Overview: You are a test subject trapped in a digital simulation. You can Shapeshift into six different geometric forms. Each form has unique physics, sizes, and abilities. You must use these forms, combined with a portal gun, to solve puzzles and escape.

2. The 6 Shapeshifter Forms
🟦 Cube: Heavy/slow. Presses plates, breaks walls.
🔵 Sphere: Fast/bouncy. Fits through pipes.
🔺 Pyramid: High friction. Climbs walls, reaches high switches.
🟢 Slime: Low gravity/sticky. Squeezes through cracks, sticks to ceilings.
⚪ Ghost: Floats. Passes through lasers/grates.
🟣 Magnet: Heavy. Pulls metal bridges, redirects lasers.

3. Mobile Controls (Touch)
🕹️ Left Joystick: Move (Forward, Backward, Left, Right)
🔘 JUMP: Tap to jump
🔄 MORPH: Tap to cycle through shapes
🔵 BLUE PORTAL: Tap to place blue portal
🟠 ORANGE PORTAL: Tap to place orange portal
📷 Camera: Auto-follows behind player

4. Puzzle Elements

Pressure Plates: Only Cube can press.

Narrow Vents: Only Sphere/Slime can fit.

Laser Grids: Only Ghost can pass.

Metal Bridges: Only Magnet can pull.

Climbable Walls: Only Pyramid can scale.

Portals: Teleport across gaps.

5. Game Modes

Single Player: 3 Rooms (Tutorial, Main, Finale)

Time Trial: Timer runs, best time saves to browser.
